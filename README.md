# Wordle Clone - Türkçe

Modern, duyarlı (mobil uyumlu) ve vite tabanlı Wordle oyunu.

## Özellikler
- 🇹🇷 Tam Türkçe Klavye ve Karakter Desteği
- 📱 %100 Mobil Uyumlu ve Dokunmatik Dostu
- ⚡ Vite + Tailwind CSS ile süper hızlı
- 🎨 Şık animasyonlar ve tasarım
- 🎉 Kazanma/Kaybetme efektleri

## Kurulum ve Çalıştırma

Proje bağımlılıklarını yükleyin:
```bash
npm install
```

Geliştirme modunda çalıştırın (Tarayıcı otomatik açılır):
```bash
npm run dev
```

Üretime hazır çıktı almak için (Build):
```bash
npm run build
```

## Mobil Cihazda Test Etme
`npm run dev` komutunu çalıştırdıktan sonra terminalde beliren "Network" adresini (örn: `http://192.168.1.X:5173`) telefonunuzun tarayıcısına girerek oynayabilirsiniz.
(Bilgisayar ve telefon aynı Wi-Fi ağında olmalı)
